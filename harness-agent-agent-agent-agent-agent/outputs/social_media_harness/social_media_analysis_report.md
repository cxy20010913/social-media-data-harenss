## 7. 问题处理建议

- [medium] 发布者IP 缺失率较高：默认不进入核心模型；若论文需要该变量，应单独说明缺失机制或改用缺失指示变量。
- [high] 是否广东 缺失率较高：默认不进入核心模型；若论文需要该变量，应单独说明缺失机制或改用缺失指示变量。
- [high] 博文ID大量重复：将观测粒度标记为传播结构观测；正式建模前需决定是否聚合到博文层级。
- [medium] 当前回归为轻量 OLS：用于方向初筛；论文结果建议增加稳健标准误、控制变量、固定效应和共线性检查。
